# Yotara Roadmap

Planning for Yotara lives on the **[Yotara Roadmap](https://github.com/users/apauldev/projects/1)** GitHub Project board, backed by [GitHub Issues](https://github.com/apauldev/Yotara/issues).

| Looking for | Go to |
|:---|:---|
| What is being worked on now, and what is next | [Yotara Roadmap board](https://github.com/users/apauldev/projects/1) |
| A specific bug or feature request | [GitHub Issues](https://github.com/apauldev/Yotara/issues) |
| Something scoped for a first contribution | [`good first issue`](https://github.com/apauldev/Yotara/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) |
| Durable architecture, decisions, and known risks | [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md) |
| What shipped, release by release | [CHANGELOG.md](./CHANGELOG.md) |
| The original MVP roadmap and retired plans | [docs/archive/](./docs/archive/README.md) |

The board is authoritative for priority and status. Issues and their Project status are the source of truth — not any document in this repository.
